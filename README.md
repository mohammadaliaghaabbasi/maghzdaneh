# 🌰 مغزدانه (Maghzdaneh) — پلتفرم تخصصی، سه‌بعدی و بازارچهٔ مغز پسته، بادام و گردو

> **«مغزدانه»** بازار تخصصی خرید و فروش دست‌اول مغز پسته، بادام و گردو است؛ از مصرف خانگی (۲۵۰ گرم) و هدایای سازمانی تا تأمین قنادی‌ها، مناقصهٔ عمده (B2B)، بازارچهٔ غرفه‌های باغداران و صادرات ارزی (FOB/CIF) — با طراحی سه‌بعدی و قابلیت نصب به‌عنوان وب‌اپلیکیشن (PWA).

📄 **برای نسخهٔ کامل معارفه و توضیح تمام بخش‌ها جهت ارائه به مشتریان و سرمایه‌گذاران، فایل [`MAGHZDANEH-OVERVIEW.md`](MAGHZDANEH-OVERVIEW.md) را مطالعه کنید.**

---

## ✨ ویژگی‌های کلیدی پلتفرم

| حوزه | امکانات پیاده‌سازی‌شده |
|---|---|
| **فروشگاه و تجربهٔ خرید (B2C)** | صفحهٔ اول سه‌بعدی تعاملی (WebGL)، کاتالوگ فیلتردار با مقایسهٔ ۴ محصول، قیمت‌گذاری پلکانی ۳ سطحی (خرده، نیم‌عمده، عمده)، انتخاب نوع فرآوری و بسته‌بندی، **میکس‌ساز اختصاصی آجیل (`mix.html`)**، هدایای سازمانی (`gifts.html`)، سبد خرید ابری و صدور پیش‌فاکتور PDF |
| **بازارچهٔ چندفروشنده (Marketplace)** | ۶ غرفهٔ نمونه از قطب‌های اصلی ایران (رفسنجان، قزوین، تویسرکان، سامان، دامغان، کوهبنان)، پنل اختصاصی غرفه‌داران (`seller.html`)، پرداخت امن امانی (Escrow)، امتیازدهی، دیدگاه خریداران و پیام مستقیم خریدار به غرفه‌دار |
| **تجارت عمده و صادرات (B2B & Export)** | تابلوی نرخ روز بورس مغز با نمودار روند ۷/۳۰/۹۰ روزه، سامانهٔ استعلام عمده (**RFQ**)، سفارش پک نمونه ۵ گرید، اشتراک تأمین دوره‌ای با ۵٪ تخفیف ثابت، پیش‌خرید فصل آینده و **پورتال صادرات دوزبانه (`export.html`)** با کد تعرفه HS و محاسبه‌گر FOB/CIF |
| **شفافیت، پیگیری و اعتماد** | **استعلام اصالت بار و شناسنامه آزمایشگاهی QR (`trace.html`)** برای هر کد پارت، **رهگیری لحظه‌ای سفارش بدون نیاز به ورود (`track.html`)**، و درخواست فاکتور رسمی شرکتی در تسویه‌حساب |
| **پنل کاربری و مدیریت اجرایی** | پنل مشتری (`account.html`) با کیف پول، آدرس‌ها، اشتراک‌ها، تیکت، صندوق پیام غرفه‌داران و کد دعوت دوستان؛ پنل مدیریت (`admin.html`) با نمودار فروش، امور مالی، سفارش‌ها، غرفه‌ها، تسویه شبا، کد تخفیف، CMS محتوا، مدیریت اتصالات خارجی و Audit Log |
| **وب‌اپلیکیشن (PWA) و موبایل** | قابل نصب روی اندروید، آیفون و دسکتاپ (`manifest.webmanifest` + `sw.js`) با نوار پایین شیشه‌ای تعاملی، دکمهٔ بازگشت هوشمند و فونت محلی فارسی وزیرمتن |

## 🚀 اجرای محلی و استقرار

### ۱. اجرای فول‌استک (Node.js)
```bash
npm install
npm run build
npm start
```
برنامه روی پورت `3000` (`http://localhost:3000`) در دسترس خواهد بود.

### ۲. اجرای استاتیک روی GitHub Pages
تمام ۲۴ صفحه به‌گونه‌ای طراحی شده‌اند که روی **GitHub Pages** نیز با فایل‌های دادهٔ محلی (`data/db.json` و `data/marketplace-seed.json`) و پشتیبانی PWA بدون خطای ۴۰۴ اجرا شوند.

### ۳. اتصال سرویس‌های واقعی (اختیاری)
متغیرهای نمونه در فایل `.env.example` تعریف شده‌اند. در نبود کلیدهای تجاری، درگاه پرداخت (زرین‌پال/شاپرک)، پیامک OTP، محاسبهٔ کرایهٔ حمل و اعلان‌های وب در **حالت دمو (Sandbox)** فعال هستند و از تب وضعیت اتصالات در `admin.html` قابل مشاهده‌اند.

## 🔐 دسترسی دمو (برای تست و معارفه)

- **پنل کاربر (`account.html`):** نام کاربری `user` | رمز عبور `user`
- **پنل مدیریت (`admin.html` یا از فرم ورود `account.html`):** نام کاربری `admin` | رمز عبور `admin`
