# 🥜 مغزدانه — فروشگاه تخصصی مغز پسته، بادام و گردو

> **«مغزدانه» = مغز + دانه.** بازاری تخصصی برای خرید و فروش مغز — با تمرکز ویژه روی مغز پسته در همه انواع آن (اکبری، فندقی، کله‌قوچی، احمدآقایی، سبز، سرخ، برشته، خلال، پودر، شکسته) به‌همراه مغز بادام و مغز گردو.
> از **دست اول (باغدار و بنه‌دار)** تا **آخرین حلقه زنجیره (مصرف‌کننده خانگی)** — خرده‌فروشی از ۲۵۰ گرم و عمده‌فروشی تا ۲۵ کیلو به بالا، با قیمت پلکانی شفاف.

| | |
|---|---|
| **وضعیت** | ✅ فعال و تست‌شده (لانچ: آبان ۱۴۰۵) |
| **زبان** | فارسی — راست‌به‌چپ (RTL) |
| **میزبانی** | GitHub Pages (استاتیک، بدون سرور) |
| **دیتابیس** | همین ریپو! `data/db.json` + سفارش‌ها در `data/orders/` |
| **پنل مدیریت** | `admin.html` — با GitHub API (بدون بک‌اند!) |

## ⚙️ چطور کار می‌کند؟ (معماری «ریپو = دیتابیس»)

```
┌─────────────┐     خواندن عمومی (بدون توکن)      ┌──────────────────┐
│  مرورگر     │ ────────────────────────────────▶ │ data/db.json     │
│  خریدار     │ ◀──────────────────────────────── │ (روی Pages)      │
└─────────────┘      سبد خرید = localStorage      └──────────────────┘
       │                                            ▲          │
       │ ادمین با توکن (GitHub Contents API)        │ کامیت    │ خواندن
       ▼                                            │          ▼
┌─────────────┐     PUT data/db.json (کامیت)        │   ┌──────────────┐
│ admin.html  │ ────────────────────────────────────┘   │ data/orders/ │
│ پنل مدیریت  │     PUT data/orders/MD-XXXX.json (سفارش) │ سفارش‌ها     │
└─────────────┘                                        └──────────────┘
```

- **بدون بک‌اند، بدون هزینه سرور.** همه‌چیز استاتیک است؛ نوشتن داده از طریق GitHub REST API انجام می‌شود که خودش کامیت می‌سازد.
- **سبد خرید** روی دستگاه خریدار (localStorage) ذخیره می‌شود — بدون کوکی ردیابی.
- **سفارش** هنگام تسویه، اگر توکن ادمین در مرورگر باشد مستقیم در ریپو ثبت می‌شود؛ در غیر این‌صورت به‌صورت محلی نگه داشته می‌شود و با تماس تلفنی نهایی می‌شود (برای لانچ اول کافی است؛ اتصال درگاه پرداخت رسمی گام بعدی است).

## 🔐 راهنمای پنل مدیریت

1. به `admin.html` بروید.
2. یک **Fine-grained Personal Access Token** بسازید (Settings → Developer settings → Personal access tokens) و فقط به همین ریپو با دسترسی **Contents: Read and write** محدودش کنید.
3. توکن را در پنل وارد کنید — توکن فقط در localStorage مرورگر خودتان ذخیره می‌شود و هرگز در کد یا سروری نوشته نمی‌شود.
4. از تب‌ها استفاده کنید: **سفارش‌ها** (آمار + جزئیات) · **محصولات** (ویرایش قیمت/موجودی، افزودن/حذف) · **تنظیمات** (تماس، ارسال، آدرس) · **JSON خام** (ویرایش مستقیم با اعتبارسنجی).
5. هر تغییر = یک کامیت روی `main` = بلافاصله زنده روی سایت (ممکن است چند دقیقه کش CDN بماند).

## 💰 قیمت‌گذاری پلکانی

| پله | حداقل | تخفیف تقریبی نسبت به خرده | مخاطب |
|---|---|---|---|
| خرده‌فروشی | ۲۵۰ گرم | — | مصرف خانگی |
| نیم‌عمده | ۵ کیلو | ~۷–۸٪ | قنادی، آجیل‌فروشی، رستوران |
| عمده | ۲۵ کیلو | ~۱۲–۱۹٪ | فروشگاه، صنایع غذایی، صادرات |

قیمت‌های اولیه بر اساس استعلام آبان ۱۴۰۵ از فروشگاه‌های آنلاین آجیل (آمین‌ناتس، گردوکان، توتپس) تنظیم شده‌اند و تاریخ آخرین به‌روزرسانی در بالای همه صفحات نمایش داده می‌شود. از پنل مدیریت، قیمت‌ها را بعد از هر نوسان بازار به‌روز کنید.
