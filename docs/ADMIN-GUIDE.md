# 🔐 راهنمای پنل مدیریت و دیتابیس گیت‌هاب

## فلسفه: ریپو = دیتابیس

این سایت هیچ سروری ندارد. داده در سه لایه زندگی می‌کند:

1. **`data/db.json`** — دیتابیس اصلی (محصولات، قیمت‌ها، تنظیمات، FAQ). عمومی خوانده می‌شود، با توکن نوشته می‌شود.
2. **`data/orders/YYYY-MM/*.json`** — سفارش‌ها، پارتیشن‌بندی ماهانه.
3. **localStorage مرورگر** — سبد خرید خریداران (بدون ثبت سرور، حریم‌خصوصی‌محور).

هر «ذخیره» در پنل ادمین = یک **کامیت روی برنچ main**. این یعنی:
- تاریخچه کامل تغییرات قیمت = `git log data/db.json`
- rollback = revert
- audit = نام نویسنده هر کامیت

## ساخت توکن (یک‌بار)

1. گیت‌هاب → Settings → Developer settings → **Personal access tokens → Fine-grained tokens**
2. Generate new token:
   - Repository access → **Only select repositories** → `maghzdaneh`
   - Permissions → Repository permissions → **Contents: Read and write**
   - Expiration: ۹۰ روز (امن‌تر)
3. توکن را کپی کنید (فقط همان‌جا نمایش داده می‌شود).
4. در سایت به `admin.html` بروید و توکن را وارد کنید.

توکن در localStorage مرورگر شما ذخیره می‌شود؛ در کد سایت یا روی گیت‌هاب نوشته نمی‌شود. برای خروج، دکمه «خروج» را بزنید تا پاک شود.

## امکانات پنل

| تب | کار |
|---|---|
| **سفارش‌ها** | آمار (تعداد، در انتظار، ارزش) + جزئیات هر سفارش و پیشنهاد عرضه |
| **محصولات و قیمت‌ها** | ویرایش سه قیمت + موجودی همه محصولات یک‌جا؛ افزودن محصول جدید؛ حذف |
| **تنظیمات سایت** | تلفن، آدرس، ساعت کاری، هزینه ارسال، سقف ارسال رایگان |
| **دیتابیس خام** | ویرایش مستقیم JSON با اعتبارسنجی — فقط برای تغییرات پیشرفته |

هر ذخیره، فیلد `price_date` را به امروز تنظیم می‌کند تا «به‌روزرسانی قیمت» بالای صفحات خودکار تغییر کند.

## ثبت سفارش خریداران — دو حالت

- **با توکن در مرورگر (حالت اپراتور):** سفارش هنگام تسویه مستقیم با PUT در `data/orders/` کامیت می‌شود.
- **بدون توکن (حالت عادی):** سفارش در localStorage همان دستگاه ذخیره و خریدار برای تأیید تلفنی راهنمایی می‌شود. برای لانچ اول، بررسی پوشه orders + پیام‌های محلی کافی است؛ پس از اتصال درگاه پرداخت، سرور کوچکی این حالت را حذف می‌کند.

## نکات امنیتی

- توکن fine-grained به همین ریپو محدود شود؛ هرگز توکن با دسترسی همه‌ریپوها ندهید.
- اگر توکن لو رفت: فوراً از گیت‌هاب Revoke کنید.
- `admin.html`، `cart.html`، `checkout.html` و `success.html` در robots.txt و متا noindex هستند و در گوگل اندکس نمی‌شوند.
